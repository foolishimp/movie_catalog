Open media in this computer's VLC

This one-time setup registers media-catalog-vlc: for your user account. The catalog can then launch VLC on the computer running your browser with the selected file's mapped smb:// network URI. It does not ask the server Mac to play the file.

Windows

  1. Download the Windows setup
  2. Open PowerShell in Downloads and run powershell -NoProfile -ExecutionPolicy Bypass -File .\install-media-catalog-vlc.ps1.
  3. Return to the catalog and choose ▶ VLC here. Allow the browser's “Open Media Catalog VLC?” prompt.

macOS

  1. Download the macOS setup
  2. Open Terminal in Downloads and run /bin/zsh ./install-media-catalog-vlc-macos.sh.
  3. Return to the catalog and choose ▶ VLC here. Allow the browser's “Open Media Catalog VLC?” prompt.

For safety, both handlers accept only SMB links to: {{ allowed_hosts | join(', ') }}.
